加密规则

        
    
          
  1. 明码：汉字按标准中文电码本译为四码（0001–9798）。数字、字母、标点用本机扩展码 99xx。
    2. 
          
  2. 密本：四码经保密代码本替代，同一字不再对应公开电码。
    3. 
          
  3. 加乱：与乱数本中的乱数组逐位相加、不进位（如 1032 + 5678 = 6600）。解密时逐位相减、不借位。
    4. 
          
  4. 指标：报首第一组为指标组 PPRC，示乱数自第 PP 页 R 行 C 列起用；指标组本身另加指标乱数遮盖。
    5. 
          
  5. 校验：报尾一组为全部明码不进位之和，加乱后附发，用以核对抄收与密钥。
    6. 
          
  6. 一次一密：每组乱数只用一次。本机记录已用位置，重用时告警。
    7. 
        

        
乱数由密钥经 PBKDF2-SHA256 / HMAC-SHA256 派生，强度取决于密钥本身，建议使用“随机生成”的 32 位数字密钥。全部运算在本机离线完成。
